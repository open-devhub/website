[DevHub](/join) uses a small, deliberate set of bots, enough to keep things running smoothly without turning every command into a guessing game. Here's what's running and what each one does.

## Active Bots

### Akinator

A game bot where members try to beat the famous mind-reading genie.

Great for casual fun, community interaction, and keeping chats active.

### Arcane

Leveling and activity tracking bot used to reward active members.

Handles XP, leaderboards, rank rewards, and progression roles.

### Bump Reminder

Automatically reminds members to bump the server on Disboard.

Helps improve server visibility and growth.

### Dank Memer

A popular economy and meme bot packed with games, commands, and collectibles.

Used mainly for fun activities and community engagement.

### Disboard

Server listing platform used to help new members discover the community.

Members can bump the server regularly to improve visibility.

### Gartic Bot

Drawing and guessing game bot inspired by Gartic-style gameplay.

Perfect for events, and casual hangouts.

### Giveaway Boat

Manages server giveaways with automated entries, rerolls, and timers.

Used for events, rewards, and community activities.

### Invite Tracker

Tracks member invites and server growth statistics.

Useful for referral rewards, milestones, and moderation insights.

### Quill

Advanced Discord developer assistant for coding, debugging, AI help, documentation lookup, and developer utilities.

Supports code execution, AI assistance, documentation lookup, and developer tooling directly within Discord.

### Rhythm

Music bot for listening to songs together in voice channels.

Supports queues, playlists, and shared listening sessions.

### Sapphire

Moderation and utility bot used to help manage the server.

Provides tools for logging, automod, safety, and moderation workflows.

### Statbot

Advanced analytics bot that tracks server activity and engagement.

Provides detailed statistics about channels, messages, and member activity.

### TempVoice

Creates temporary voice channels automatically when members join.

Allows users to have private or customizable voice spaces.

### Rael

AI assistant bot for chatting, asking questions, generating content, and browsing information directly inside Discord.

Supports multiple personalities and conversational experiences.

### Panda

General-purpose server bot used for moderation, utilities, tickets, suggestions, counting, starboard, welcomes, and more.

Provides a wide range of features for managing the server and enhancing the community experience.

## Bot Commands

Use bot commands in #terminal unless a command is specifically designed for another channel (e.g. `/suggest` works anywhere). Running commands in #dev-chat or #chat is fine occasionally, but if you're experimenting, take it to the right place.

> [!warning] Spamming bot commands or attempting to exploit bot behavior will result in a warning, timeout or ban depending on the severity. Bots are tools, not toys.

## Suggesting a New Bot

See the [Adding a Bot](/pages/adding-a-bot) page for the proposal process. We review all bot suggestions carefully, security, permissions, and actual usefulness all factor into the decision.
